# Rock Paper Scissors ✂️

A simple Rock Paper Scissors game built with vanilla JavaScript.
Play against the computer and see if you win!

---

## Features
- 🪨 Rock, 📄 Paper, ✂️ Scissors choices
- 🤖 Random computer choice
- 🏆 Win, lose, or tie result
- ⚡ Instant result via alert

---

## Tech Used
- HTML
- JavaScript (Vanilla)

---

## How to Run
1. Clone the repo
2. Open `index.html` in your browser
