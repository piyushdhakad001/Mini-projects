# Mini Projects 🚀

A collection of beginner JavaScript mini projects built with vanilla HTML, CSS, and JavaScript.

---

## Projects

### 🧮 Calculator

A basic calculator supporting addition, subtraction, multiplication, and division.

### 🛒 Cart Quantity

A cart manager to add, remove, and reset items with a maximum limit of 10.

### 🪙 Coin Flip Game

Guess heads or tails and play against random computer results. Tracks wins and losses.

### ✂️ Rock Paper Scissors

Play Rock Paper Scissors against the computer with instant results.

---

## Tech Used

- HTML
- JavaScript (Vanilla)

---

## How to Run

1. Clone the repo
2. Open any project folder
3. Open `index.html` in your browser
