# Coin Flip Game 🪙

A simple coin flip game built with vanilla JavaScript.
Guess heads or tails and see if you win!

---

## Features
- 🪙 Flip a coin with heads or tails guess
- ✅ Tracks wins and losses
- 🎲 Random result every flip
- 📊 Live score updates

---

## Tech Used
- HTML
- JavaScript (Vanilla)

---

## How to Run
1. Clone the repo
2. Open `index.html` in your browser
